# Contributors

twelveswaras is a community-owned public good. This file credits the people who have grown
its openly-licensed **data commons** by contributing recordings. Code contributors are
credited through the Git history and [`CITATION.cff`](CITATION.cff); this file is for the
audio commons specifically, whose CC-BY-4.0 licence is built on attribution.

## How attribution works

Contributing a clip is **anonymous by default**. When you contribute at
[twelveswaras.com/contribute](https://twelveswaras.com/contribute) there is an optional
**Credit** field: type a name or handle and you are credited here, and, if you also release
the clip publicly under CC-BY, alongside your clip in the open dataset. Leave it blank and
your contribution stays anonymous. It is a public display name only, never an email or other
contact detail.

Being credited is independent of whether the raw audio is public. The credit recognises the
contribution to the commons whether the clip is released CC-BY or kept private (used only to
improve the model, never published). You can ask to be added, changed, or removed at any time
by opening an issue or writing to the contact in [`SECURITY.md`](SECURITY.md).

## Data commons contributors

- **[Skanda (Shaale)](https://shaale.com)** contributed the first recordings to the
  commons: **Lathangi**, **Arabhi**, **Kuntala Varali** (Carnatic) and **Hameer**
  (Hindustani). These vocal recordings reach beyond the raagas the model is currently
  trained on, seeding new raagas for a future model to learn.
