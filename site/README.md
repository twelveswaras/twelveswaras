# twelveswaras.com static site

The public site (twelveswaras.com), served from `site/` by Cloudflare Pages. Pure static, with no
build step at deploy time; the raaga pages and open data are pre-generated from a data layer.

## What's here
- `index.html`: the landing page (about, how-it-works, FAQ, embedded recognizer).
- `raaga/`: the Raaga Explorer, a browse index grouped by melakarta (`raaga/index.html`) plus one
  page per raaga (`raaga/<slug>.html`), generated by `../tools/build_pages.py`.
- `listen/`: the ear-trainer.
- `data/raagas.json`: open reference data (CC-BY-4.0), from `../tools/build_data.py`.
- `llms.txt`: a plain-text project guide for LLMs / agents.
- Icons + share card: `favicon.svg` / `.ico` / `-16` / `-32`, `apple-touch-icon.png`,
  `icon-192.png` / `icon-512.png` (manifest `any`), `icon-maskable-512.png` (manifest `maskable`:
  full-bleed, mark inside the safe zone, from `icon-maskable.svg`), `og.png`. The PNGs are
  rasterized from the `.svg` sources.
- `install-button.js` / `.css`: the "Install app" button on every page that links the manifest.
- `screenshots/home-narrow.webp` / `home-wide.webp`: the home page on a phone and on a desktop,
  shown in Chrome's install dialog (manifest `screenshots`). Not cached by the worker.

## Regenerate
    python -m tools.merge_enrichment   # fold the draft reference + tell/rasa into the reference JSON
    python -m tools.build_data         # -> site/data/raagas.json + site/llms.txt
    python -m tools.build_pages        # -> site/raaga/*.html + the grouped index

    # icons / OG (only when the .svg sources change), from the repo root:
    rsvg-convert -w 1200 -h 630 site/og.svg     -o site/og.png
    rsvg-convert -w 180  -h 180 site/icon.svg   -o site/apple-touch-icon.png
    rsvg-convert -w 192  -h 192 site/icon.svg   -o site/icon-192.png
    rsvg-convert -w 512  -h 512 site/icon.svg   -o site/icon-512.png
    rsvg-convert -w 512  -h 512 site/icon-maskable.svg -o site/icon-maskable-512.png
    rsvg-convert -w 32   -h 32  site/favicon.svg -o site/favicon-32.png
    rsvg-convert -w 16   -h 16  site/favicon.svg -o site/favicon-16.png
    magick site/favicon.svg -background none -define icon:auto-resize=16,32,48 site/favicon.ico

    # install-dialog screenshots (after a visible change to the home page):
    cd e2e && npm run screenshots

## Deploy
A merge to `main` deploys `site/` to Cloudflare Pages (project `twelveswaras-site`) from the
`deploy` job in `.github/workflows/ci.yml`, once the verify, lint and e2e jobs pass. Pull requests
never deploy, and neither does a manual `workflow_dispatch` run (the job deploys only on a push).
To redeploy without a code change, with Cloudflare credentials in the environment:

    npx --yes wrangler@4 pages deploy site --project-name=twelveswaras-site --branch=main

## Wire the recognizer
`index.html` runs the recognizer first-party: it posts audio to `/api/identify` on
twelveswaras.com, which a Cloudflare Worker (`../cloudflare/worker`) forwards to the recognizer
container (`../cloudflare/recognizer`). There is no iframe and no third-party embed. See
`../cloudflare/DEPLOY.md`.
